## Phase Goal

**As a** new user, **I want to** download the app's content once from a reliable backend and then use it fully offline, **so that** I can use Ro'i anywhere.

<objective>
Define the backend SQLite Drizzle schema (`content_meta`, `verses`, `names_of_god`, `blessings`, `suggestions`, `audit_log`), WAL database initializer, and generated Drizzle migrations, then build the local Arabic JSON seed fixture, atomic `.json.gz` snapshot builder, and idempotent `--dry-run` seed CLI without Sanity API dependencies (`BE-01`, `BE-05`, `BE-07`, `D-05`, `D-10`).

Purpose: Establish the durable SQLite persistence layer, migrations, and initial snapshot-generation pipeline before standing up the NestJS read/write endpoints.
Output: `backend/drizzle.config.ts`, `schema.ts`, `client.ts`, `backend/drizzle/*`, `initial-content.json`, `snapshot-builder.ts`, `seed.ts`, and `seed.test.ts`.
</objective>
