## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (`IBMPlexSansArabic-Regular`) | 1.5 (24px) |
| Label | 14px (`text-sm`) | 700 (`IBMPlexSansArabic-Bold`) on active CTA/chip; 400 (`IBMPlexSansArabic-Regular`) on secondary captions | 1.4 (20px) |
| Heading | 20px (`text-xl`) | 700 (`IBMPlexSansArabic-Bold`) | 1.3 (26px) |
| Display | 28px (`text-3xl`) | 700 (`IBMPlexSansArabic-Bold`) | 1.2 (34px) |

Typography rules:
- Strictly **4** UI sizes (`14px`, `16px`, `20px`, `28px`) and **2** UI weights (`400` `IBMPlexSansArabic-Regular`, `700` `IBMPlexSansArabic-Bold`).
- **Never** apply `tracking-*` utility classes (breaks Arabic ligature joining and fails `app/__tests__/guards.test.ts`).
- **Never** pass `allowFontScaling={false}` (fails `app/__tests__/guards.test.ts`); cap large headings at `maxFontSizeMultiplier={1.3}` (`MAX_FONT_SIZE_MULTIPLIER` in `app/constants/theme.ts`).
- Any Scripture sample rendered on screen must use `<Scripture>` (`Amiri-Regular`, user-selected `SCRIPTURE_SIZES` `[18, 20, 23, 27, 32]`, line-height `1.8`).
- All counts, dates, and stage numbers use `toArabicDigits()` from `@roi/shared` (Arabic-Indic digits `٠١٢٣٤٥٦٧٨٩`).

## Screen & Interaction Contracts

### 1. First-Launch Offline Gate (`HOME-06`, `D-04`)
- **Trigger:** `lastContentVersion === 0` AND `!isOnline` (no downloaded library yet and network unavailable). Bypassed only when `DEV_TOOLS_ENABLED && segments[0] === '(dev)'` (`02-RESEARCH.md` Pitfall 7).
- **Layout:** Centered single-column `bg-background` container (`px-6 py-8`), warm `bg-card` rounded-2xl (`rounded-2xl border border-border p-6`) holding:
  1. `WifiOff` icon (`Icon` size `32`, `text-accent`)
  2. Display/Heading title `"محتاجين إنترنت أول مرة بس"` (`text-xl font-bold text-foreground text-center`)
  3. Reassuring Egyptian Arabic body `"محتاجين إنترنت أول مرة بس عشان ننزّل لك مكتبة روعي، وبعدها كل حاجة شغالة أوفلاين"` (`text-base text-muted-foreground text-center`)
  4. Primary CTA `Pressable` `"جرّب تاني"` (`min-h-[44px] rounded-xl bg-primary px-6 py-4`, `text-sm font-bold text-primary-foreground`)
- **Interaction:** Tapping `"جرّب تاني"` re-checks `Network.getNetworkStateAsync()` and starts/resumes download immediately if online. If `useNetworkState()` fires an online transition while the gate is visible, download starts automatically without requiring a tap.

### 2. Resumable First-Download Progress (`HOME-07`, `D-01`, `D-02`)
- **Trigger:** `lastContentVersion === 0` AND (`status === 'downloading'` OR `status === 'paused'` OR `status === 'error'`).
- **Layout:** Centered single-column `bg-background` container (`px-6 py-8`), warm `bg-card` rounded-2xl (`border border-border p-6 gap-4`) holding:
  1. Title `"بنجهّز لك مكتبة روعي..."` (`text-xl font-bold text-foreground text-center`)
  2. Current stage label (`text-base text-foreground text-center`): `"جاري تنزيل: الآيات"` (step 1 of 3), `"جاري تنزيل: أسماء الله"` (step 2 of 3), or `"جاري تنزيل: البركات"` (step 3 of 3) — **no percentages or byte counts**.
  3. Calm progress bar track (`h-3 w-full overflow-hidden rounded-full bg-muted`, `accessibilityRole="progressbar"`, `accessibilityLabel` set to the current stage label):
     - Active fill bar (`h-full rounded-full bg-accent`) animated with Reanimated (`ReduceMotion.System`) progressing cleanly across the 3 stages (`1/3`, `2/3`, `3/3`, expanding from logical `start` edge inside forced RTL — never hardcoded `left-0`).
  4. When connectivity drops mid-batch (`status === 'paused'`): show calm notice `"الاتصال انقطع — هنكمّل تلقائي من آخر جزء أول ما الإنترنت يرجع"` (`text-sm text-muted-foreground text-center`) + `"جرّب تاني"` CTA (`min-h-[44px] bg-primary`).
  5. When fetch/validation fails while online (`status === 'error'`): show `"حصلت مشكلة في التنزيل دلوقتي — تأكد من الإنترنت واضغط جرّب تاني"` (`text-sm text-destructive text-center`) + `"جرّب تاني"` CTA (`min-h-[44px] bg-primary`).
- **Atomicity invariant:** Staging files persist per stage in `expo-file-system`; committed SQLite tables remain untouched until all 3 stages verify at the same `contentVersion` and commit inside one atomic transaction.

### 3. Post-Download `"المكتبة جاهزة"` Ready Screen (`D-04`)
- **Trigger:** `lastContentVersion > 0` (immediate offline launch on subsequent opens; silent background delta sync runs throttled every ~6h with zero UI interruption per `D-03`).
- **Layout:** Centered `bg-background` container (`px-6 py-8`) preserving Phase 1 `app/app/index.tsx` structure:
  1. App Display title `"روعي"` (`text-3xl font-bold text-foreground text-center`)
  2. `"المكتبة جاهزة"` status header with `CheckCircle2` (`Icon` size `24`, `text-accent`) + `"كل حاجة بقت على جهازك وشغالة أوفلاين"` (`text-base text-muted-foreground text-center`)
  3. Summary counts card (`w-full rounded-2xl border border-border bg-card p-4 gap-2`): three horizontal RTL rows (`flex-row items-center justify-between py-2`) displaying `"الآيات"`, `"أسماء الله"`, and `"البركات"` on the `start` side and their Arabic-Indic counts (`toArabicDigits(...)`) in `text-xl font-bold text-foreground` on the `end` side.
  4. Preserved Phase 1 Theme Switcher (`نظام` / `فاتح` / `داكن`, `accessibilityRole="radiogroup"`, `min-h-[44px]`, active chip `bg-primary` / `text-primary-foreground`).
  5. Preserved Phase 1 `(dev)` links (`شاشة اختبار النصوص`, `شاشة فحص التكاملات`) rendered strictly when `DEV_TOOLS_ENABLED` is true.

### 4. RTL & Static Guard Constraints (`app/__tests__/guards.test.ts`)
- Use logical Tailwind utilities only: `start-*`, `end-*`, `ps-*`, `pe-*`, `ms-*`, `me-*`, `text-start`, `text-center`.
- Forbidden classes (will fail `bun run test`): `ml-*`, `mr-*`, `pl-*`, `pr-*`, `left-*`, `right-*`, `text-left`, `text-right`, `border-l-*`, `border-r-*`, `tracking-*`.
- Forbidden props: `allowFontScaling={false}`, `offlineAccess`, `serverAuthCode`, `setUserId`, `setUserProperty`.
