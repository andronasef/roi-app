## Phase Goal

**As a** new user, **I want to** download the app's content once from a reliable backend and then use it fully offline, **so that** I can use Ro'i anywhere.

<objective>
Establish the shared Phase 2 content, snapshot, seed, and suggestion contracts in `@roi/shared`, install the NestJS 12 / Apollo 5 / Drizzle / SQLite backend stack in `backend/` with `unplugin-swc` Vitest support, and create the backend TypeScript, env validation (`D-06`, `D-10`), and ESM/CJS-safe path resolver (`resolveBackendRoot` / `resolveBackendPath`).

Purpose: Lock one shared validation contract across backend and mobile and stand up the backend runtime/config foundation before DB migrations and NestJS endpoints are built.
Output: Extended `@roi/shared` schemas, configured `backend/` workspace, `env.ts`, and `paths.ts`.
</objective>
