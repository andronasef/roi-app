## Phase Goal

**As a** new user, **I want to** download the app's content once from a reliable backend and then use it fully offline, **so that** I can use Ro'i anywhere.

<objective>
Implement the hardened Express/Nest bootstrap (`main.ts` + `hardening.test.ts`, `BE-04`, `D-06`, `D-09`) and the Google-authenticated `submitSuggestion` GraphQL mutation (`BE-03`, `D-10`..`D-12`) with `GoogleAuthGuard` verifying `roi-app-515721` ID tokens via `google-auth-library`, `@roi/shared` Zod validation (`ZodValidationPipe`), and a durable SQLite 10/day per Google account rate limit, wired into `AppModule` and verified with Supertest.

Purpose: Lock down HTTP/CORS/proxy/payload hardening on Express and allow signed-in users to suggest verses, names of God, or blessings safely into the `pending` moderation queue without storing personal app data on our servers (`SYNC-07` intact).
Output: `main.ts`, `hardening.test.ts`, `GoogleAuthGuard`, `ZodValidationPipe`, `SuggestionsService`, `SuggestionsResolver`, updated `AppModule`, and `suggestions.test.ts`.
</objective>
