## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App to Google Analytics and Crashlytics | Events and crash reports leave the device |
| App to Google Sign-In | OAuth tokens enter the app process |
| App data to home and lock screen | Widget content is visible without unlocking the app |
| Headless widget task to on-device database | Android runs app JS without UI and opens the database |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-16 | Information disclosure | Analytics events | high | mitigate | track() accepts only AllowedEvent names and passes no parameters (type plus static test); setUserId and setUserProperty are banned by the 01-04 guard test |
| T-01-17 | Information disclosure | Crash reports from uncaught JS errors | high | mitigate | installGlobalErrorScrubber replaces every uncaught error with a known code before Crashlytics' handler sees it; scrub tested with a multi-line sentinel; release-build sentinel check in plan 01-08 |
| T-01-18 | Information disclosure | Collection before consent | medium | mitigate | firebase.json turns auto-collection and screen reporting off; collection turns on only through setTelemetryConsent from the dev spike switch in this phase (consent UX is Phase 9) |
| T-01-19 | Elevation of privilege | Google tokens | high | mitigate | No offline-access flag, no server auth code, no extra scopes (guard test); tokens are never displayed, logged or stored; the spike row signs out after checking |
| T-01-20 | Information disclosure | Widget content and the headless handler | low | mitigate | Spike widgets show a public fixture verse and a counter only; the handler reads one settings row and never throws; privacy-safe widget defaults are WDG-05 in a later phase |
| T-01-SC | Tampering | Firebase, Google Sign-In and widget packages | high | mitigate | No install in this plan; all packages came through the 01-01 blocking-human legitimacy gate with exact pins |
