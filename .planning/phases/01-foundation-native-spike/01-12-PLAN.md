## Phase Goal

**As a** solo owner, **I want to** run an Arabic RTL app on real phones with a sync-ready database and proven native integrations, **so that** feature work never rests on guesses.

<objective>
Build the privacy-first telemetry choke point (REL-01): one module that alone imports Firebase, a closed list of parameterless analytics events, collection off until consent, and a global error scrubber that strips every uncaught error's message before Crashlytics sees it.

Purpose: prayer, name and verse text are among the most sensitive data a user can have; this plan makes it structurally impossible for them to leave the device through analytics or crash reports. The spike rows that exercise it on devices are added in plan 01-14; the release-build sentinel check runs in plan 01-16.
Output: telemetry constants, pure scrubber, Firebase service, tests, firebase.json, startup wiring.

No package or app.json change: plan 01-06 installed Firebase and plan 01-07 configured it. Runs in parallel with plans 01-11 (database) and 01-13 (widgets): no shared files.
</objective>
