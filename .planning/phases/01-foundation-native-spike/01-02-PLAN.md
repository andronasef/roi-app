## Phase Goal

**As a** solo owner, **I want to** run an Arabic RTL app on real phones with a sync-ready database and proven native integrations, **so that** feature work never rests on guesses.

<objective>
Owner-only account setup that no code can do: Apple App Group and device registration, Expo sign-in, phone preparation, and the Firebase project with Google OAuth clients. Runs in parallel with plan 01-03 (monorepo and shared package), so code work does not wait on console clicks.

Purpose: FND-09 needs Firebase, Google Sign-In and both widget systems on real phones; each needs an account object only the owner can create. REL-01 privacy starts here: Analytics data sharing and Google signals are switched off at the project level, and config files never enter git.
Output: account objects in Apple, Expo, Firebase and Google Cloud; the two Firebase config files stored outside the repository; their paths and the non-secret ids recorded in 01-02-SUMMARY.md.

Human-only plan, so no tracer task. The Android OAuth client needs the EAS keystore SHA-1, which only exists after the EAS project is linked; that step is in plan 01-07 Task 1.
</objective>
