## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Device storage to OS backup | The SQLite file could be copied into cloud backups |
| Build config to app binary | Values in app.json, app.config.js and env reach the shipped binary |
| Local secrets to generated native projects | Signing passwords flow from .signing.env into android/gradle.properties |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-13 | Information disclosure | Android backup of roi.db | high | mitigate | android.allowBackup false in app.json, confirmed in the generated manifest by the Task 2 verify; iOS backup exclusion is decided in Phase 9 |
| T-01-14 | Information disclosure | Firebase config files and signing secrets | high | mitigate | Firebase files sit at the app root and are gitignored at root and in app/.gitignore; app.json holds relative file names only; .signing.env and key.jks are gitignored and read only by app.config.js, which never logs them and writes them only into the gitignored android/ folder; the Task 2 gate checks the ignore rules and the plan 01-10 guard test fails if git tracks any of them |
| T-01-15 | Information disclosure | Drizzle query logging | medium | mitigate | No logger on the Drizzle client; nothing logs bound parameters |
| T-01-SC | Tampering | Native config plugins | high | mitigate | All plugin packages came through the 01-01 blocking-human gate and were installed in 01-06; no new package installed in this plan |
</threat_model>
