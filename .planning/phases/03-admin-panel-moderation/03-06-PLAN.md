## Phase Goal

**As a** content owner, **I want to** add and moderate verses, names and blessings in a safe admin panel, **so that** the app's content stays correct without code changes.

<objective>
Wire the complete admin GraphQL API client (`admin-api.ts`) and build the remaining admin SPA screens: `CatalogPage` (Verses, Names of God, Blessings with `matches()` search and Active/Deleted restore), `AuditLogPage` (read-only audit table), `ModerationQueuePage` (`Pending` / `Accepted` / `Rejected` tabs + one-click Reject), and `SuggestionReviewPage` (Submitter Context card + full `ItemEditorWorkspace` + atomic Accept & Publish / Reject + `409` conflict handling) (`ADM-02`, `ADM-07`, `BE-05`, `D-09`..`D-13`).

Purpose: Complete the full user-facing admin workflow from login to content authoring, soft-delete/restore, audit inspection, and suggestion moderation.
Output: `admin-api.ts`, 4 full pages wired into `main.tsx` routes, and passing `catalog.test.tsx` + `moderation-queue.test.tsx`.
</objective>
