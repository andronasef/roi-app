## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser / GIS -> `adminLogin` GraphQL mutation | Untrusted Google ID tokens and email claims cross into backend auth |
| Browser cookie + headers -> `AdminAuthGuard` | Session cookie and CSRF header cross into privileged admin resolvers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02 | Spoofing | `AdminAuthService.authenticateGoogleIdToken` | critical | mitigate | Verify Google ID token signature and `audience: env.GOOGLE_CLIENT_IDS` via `OAuth2Client.verifyIdToken`, require `email_verified === true`, and enforce case-insensitive membership in `env.ADMIN_EMAILS` |
| T-03-03 | Tampering | `AdminAuthGuard` CSRF surface on cookie auth | high | mitigate | Set `SameSite=Lax`, `HttpOnly`, `Secure` (prod) on `roi_admin_session` cookie, rely on Apollo `csrfPrevention`, and enforce custom `x-roi-admin: 1` header on every guarded request |
| T-03-04 | Cryptographic Failure | `ADMIN_JWT_SECRET` signing in production | high | mitigate | Fail closed (`ServiceUnavailableException`) in `AdminAuthService.getSigningSecret()` whenever `NODE_ENV === 'production'` and `ADMIN_JWT_SECRET` is missing or `< 32` characters |
| T-03-05 | Elevation of Privilege | Revoked admin still holding a 14-day cookie | medium | mitigate | `AdminAuthService.verifySessionToken` re-checks `email` against `env.ADMIN_EMAILS` on every guarded request so removing an email + restarting immediately invalidates existing cookies |
| T-03-SC | Tampering | `@nestjs/jwt`, `cookie-parser`, `@types/cookie-parser` installs | high | mitigate | Install only exact versions approved in Plan 03-01 (`03-01-SUMMARY.md`) |
</threat_model>
