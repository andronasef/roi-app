## Spacing Scale

| md | 16px | Default card padding (`p-4`), form field stack gap (`gap-4`), toolbar padding, grid gutters |
| lg | 24px | Section card padding (`p-6`), split editor-to-preview gap (`gap-6`), page content padding |

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px (`text-sm`) | 400 (`normal`) for metadata/captions/table headers; 700 (`bold`) for active badges, buttons, and tabs | 1.4 (`20px`) |
| Body | 16px (`text-base`) | 400 (`normal`) | 1.5 (`24px`) |
| Heading | 20px (`text-xl`) | 700 (`bold`) | 1.3 (`26px`) |
| Display | 28px (`text-3xl`) | 700 (`bold`) | 1.2 (`34px`) |

Typography rules:
- Strictly **4** UI sizes (`14px`, `16px`, `20px`, `28px`) and **2** font weights (`400`, `700`) across the entire admin SPA. (Both `IBM Plex Sans Arabic`, `Inter`, and `Amiri` ship native `400` and `700` faces — zero synthetic bold.)
- **Arabic ligature rule:** Never apply positive `tracking-*` letter-spacing to Arabic UI or Arabic content fields (`dir="rtl"`).
- **Live Mobile Preview (`D-07`):** Verse previews render inside the mobile preview card at `20px` (Heading slot) with `Amiri` (`font-serif`) and `leading-[1.8]` to match mobile `<Scripture>` (`app/constants/theme.ts`), while Names of God and Blessings render in `IBM Plex Sans Arabic` at `16px` (`1.5` line-height) with `H2` (`20px`) / `H3` (`16px` bold) Markdown headings.
- **Digits:** Arabic UI mode formats numeric counts, dates, and version numbers with `toArabicDigits()` and `formatArabicDate()` from `@roi/shared`; English UI mode uses standard ASCII digits and ISO/short English dates.

## Screen & Interaction Contracts

### 1. Visual Hierarchy & Layout Shell (`D-12`, `D-14`)
- **Primary Visual Anchors (per screen):**
  1. **Sign-In Gate (`/admin/login`):** Centered warm-paper `Card` (`max-w-md`) on `#FAF5EB` canvas; anchor is the Ro'i Admin title + Google Sign-In button.
  2. **Catalog Views (`/admin/verses`, `/admin/names`, `/admin/blessings`):** Top action header (`Add New ...` CTA + search bar + `Active / Deleted` tabs); anchor is the primary catalog table with `dir="rtl"` Arabic content rows.
  3. **Split Content Editor (`/admin/:type/new`, `/admin/:type/:id`):** Two-column workspace (`xl:grid-cols-[minmax(0,1fr)_360px]`); anchor is the Tiptap editor block on the `start` column paired with the sticky mobile preview card on the `end` column.
  4. **Suggestion Review (`/admin/suggestions/:id`):** Three-part focal flow: compact Submitter Context card at top (`email`, timestamp, accepted/rejected/pending counts) → Split Editor + Live Preview → fixed/bottom Moderation Bar (`Accept & Publish Suggestion` + `Reject Suggestion`).
  5. **Audit Log (`/admin/audit-log`):** Filter bar (`action`, `entityType`) above a dense, scannable read-only table displaying timestamp, `actorEmail`, `action` badge, `entityType`, `entityId`, `contentVersion`, and expandable `summaryJson`.
- **RTL & Bilingual Logical CSS Invariant (`D-12`):**
  - Root layout container switches `dir={lang === 'ar' ? 'rtl' : 'ltr'}` and `lang={lang}`.
  - Every layout utility uses Tailwind v4 logical properties (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`, `border-s-*`). Physical `ml-*`, `mr-*`, `pl-*`, `pr-*`, `left-*`, `right-*`, `text-left`, `text-right` are forbidden.
  - Every content input (`ref`, `title`, `verseRef`, `RichTextChipEditor`, test-name input, catalog text cells, suggestion text views, and `LiveMobilePreview`) carries explicit `dir="rtl"` and `lang="ar"` even when UI shell language is `en`.
- **Accessibility:** Every icon-only button (Tiptap toolbar buttons `Bold`, `Italic`, `H2`, `H3`, `Bullet List`, `Blockquote`, `Insert Name Chip`, table row `Edit`/`Delete`/`Restore`, and modal close icons) MUST have both an `aria-label` in the active UI language and a `Tooltip` showing the action name and keyboard shortcut.

### 2. Auth, CSRF & Mid-Edit Expiry Protection (`ADM-01`, `D-01`..`D-03`, `D-14`)
- **Cookie & CSRF Transport (`D-02`, `D-14`):** Backend serves `/admin` static SPA from the same origin in production and accepts CORS from `ADMIN_ORIGINS` (`http://localhost:5173`) in dev. Admin GraphQL client sets `credentials: 'include'` and attaches custom header `x-roi-admin-csrf: 1` (matched on backend).
- **Allowlist Gate (`D-01`):** `google-auth-library` verifies ID token (`email_verified === true`) and checks lower-cased email against `ADMIN_EMAILS`. Non-allowlisted accounts see the `403` allowlist error copy inline on the login card.
- **Mid-Edit Expiry Protection (`D-03`):**
  - A global GraphQL fetch wrapper intercepts `401` / `UNAUTHENTICATED` responses.
  - Step 1: Attempt silent Google GIS re-authentication (`google.accounts.id.prompt()` / silent credential renewal) while holding the failed request.
  - Step 2: If silent renewal does not yield a fresh ID token, open `ReauthModal` (`Dialog`) in-place over the active editor.
  - **Invariant:** Form values, Tiptap ProseMirror document state, and `textFemale` non-destructive cache MUST remain mounted and untouched in React state throughout re-authentication.

### 3. Tiptap 3 Chip Editor & Serialization (`ADM-02`..`ADM-06`, `D-04`..`D-08`)
- **Editor Modes (`D-04`):**
  - `verse`: Plain-text mode (only paragraph + hardBreak + atomic `nameChip` node; paste strips external HTML/Markdown formatting; Enter inserts line break or paragraph without headings/lists/bold/italic).
  - `name_of_god` & `blessing`: Rich-text mode supporting ONLY **Bold**, **Italic**, **H2**, **H3**, **Bullet List**, **Blockquote**, and atomic **`nameChip`**.
- **Atomic `{الاسم}` Chip Node (`ADM-04`):**
  - Rendered via Tiptap `Node.create({ name: 'nameChip', group: 'inline', inline: true, atom: true, draggable: true })` and React `NodeViewWrapper`.
  - Visual chip: `inline-flex items-center gap-1 rounded-md border border-accent/40 bg-accent/15 px-2 py-1 text-sm font-bold text-accent align-baseline select-none` displaying a small user icon + `"الاسم"`. Raw `{الاسم}` NEVER appears in the editor surface.
  - **Required interactions (acceptance-tested):**
    1. Toolbar button `"إدراج {الاسم}"` / `"Insert Name Chip"` inserts the chip at the current selection and refocuses the editor.
    2. Dragging a chip mid-sentence moves it cleanly without deleting it (`CLAUDE.md` §5 regression check).
    3. Backspace/Delete adjacent to a chip deletes the entire chip atomically.
    4. Pasting plain text containing `{الاسم}` (via `handlePaste` / `InputRule` or Markdown parser) converts `{الاسم}` into chip nodes automatically.
    5. Copy/paste between Male and Female editors preserves chips and allowed Markdown formatting.
- **Gender Toggle & Non-Destructive State (`D-05`):**
  - `"نفس النص للذكر والأنثى"` / `"Same text for male & female"` switch.
  - **ON:** Single editor (`text`). If previously OFF, `textFemale` remains preserved in component state (hidden, not erased) so toggling back OFF restores the draft. Saving with switch ON sends `textFemale: null`.
  - **OFF:** Two editors side-by-side (`grid-cols-1 md:grid-cols-2 gap-4`): Male (`text`) on `start` side, Female (`textFemale`) on `end` side; both required (`min 1` non-whitespace char).
- **Minimal Fields (`D-08`):** Forms expose ONLY `ref` (verses), `title` (names/blessings), `verseRef` (optional for blessings), `text`, and `textFemale`. `tags` and `sortOrder` are never shown in v1 UI.
- **Validation & One-Sided Warning (`D-06`):**
  - Client-side Zod check using `personalizedTextSchema` from `@roi/shared` blocks saving when any `{…}` token other than `{الاسم}` is present.
  - When switch is OFF and `(hasName(text) !== hasName(textFemale))`, show the non-blocking amber warning banner above the Save button while keeping `"Save Changes"` enabled.

### 4. Live Mobile Preview (`ADM-05`, `D-07`)
- Powered directly by `personalize({ text, textFemale }, { name: testName, gender })` from `@roi/shared`.
- Preview controls:
  - Test Name input (`dir="rtl"`, defaults to `"مينا"` or `"سارة"` depending on gender toggle, with quick `"تفريغ للاختبار المحايد"` / `"Clear for neutral"` button to test empty-name whitespace cleanup).
  - Gender Toggle (`ذكر` / `أنثى`).
- Renders the resulting Markdown subset (`H2`, `H3`, `Bold`, `Italic`, `Bullet List`, `Blockquote`) for `name_of_god`/`blessing` or `Amiri` `20px` `leading-[1.8]` plain text for `verse` inside a warm-paper mobile card frame (`rounded-2xl border border-border bg-background p-6 shadow-sm`).
