## Phase Goal

**As a** content owner, **I want to** add and moderate verses, names and blessings in a safe admin panel, **so that** the app's content stays correct without code changes.

<objective>
Implement the complete authenticated backend GraphQL API for admin content management (`ADM-02`, `ADM-06`, `D-06`, `D-08`, `D-13`), read-only audit log inspection (`BE-05`, `D-13`), and suggestion moderation with concurrent-moderation protection (`ADM-07`, `D-09`..`D-11`).

Purpose: Provide the full backend contract that the admin SPA consumes for catalog CRUD, soft-delete/restore, delta/snapshot publishing, audit logs, and suggestion review.
Output: `admin-content/`, `admin-audit/`, and `admin-moderation/` NestJS modules wired into `AppModule` with comprehensive Supertest GraphQL integration tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin GraphQL inputs -> `ZodValidationPipe` -> SQLite | Untrusted strings, brace tokens, and optional fields enter public content tables |
| Concurrent admin requests -> `suggestions` state machine | Two admins attempting to moderate the same pending suggestion concurrently |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06 | Tampering | `AdminContentResolver` & `AdminModerationResolver` input validation | high | mitigate | Enforce `ZodValidationPipe` backed by `@roi/shared` `personalizedTextSchema` on every create/update/accept mutation to reject invalid brace tokens (`{...}` != `{الاسم}`) and oversized strings |
| T-03-07 | Tampering | Concurrent moderation race (`acceptSuggestion` / `rejectSuggestion`) | high | mitigate | Execute conditional `UPDATE suggestions ... WHERE id = ? AND status = 'pending'` inside `sqlite.transaction().immediate()` and throw `ConflictException` when `changes !== 1`, rolling back `contentMeta` and `audit_log` |
| T-03-08 | Repudiation | Content and moderation mutations missing accountability | medium | mitigate | Route all public writes through `ContentService.applyContentMutation()` and write `audit_log` inside the `rejectSuggestion` transaction with `actorEmail` from verified `req.adminUser` |
| T-03-SC | Tampering | Workspace package dependencies | high | mitigate | No new npm packages installed in this plan; relies only on Plan 03-01 approved lockfile |
</threat_model>
