## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (`IBMPlexSansArabic-Regular`) | 1.5 (24px) |
| Label | 14px (`text-sm`) | 700 (`IBMPlexSansArabic-Bold`) on buttons, active tabs, chips, and badges; 400 (`IBMPlexSansArabic-Regular`) on captions and helper hints | 1.4 (20px) |
| Heading | 20px (`text-xl`) | 700 (`IBMPlexSansArabic-Bold`) | 1.3 (26px) |
| Display | 28px (`text-3xl`) | 700 (`IBMPlexSansArabic-Bold`) | 1.2 (34px) |

Typography rules:
- Strictly **4** UI sizes (`14px`, `16px`, `20px`, `28px`) and **2** UI weights (`400` `IBMPlexSansArabic-Regular`, `700` `IBMPlexSansArabic-Bold`).
- **Never** apply `tracking-*` utility classes (breaks Arabic ligature joining and fails `app/__tests__/guards.test.ts`).
- **Never** pass `allowFontScaling={false}` (fails `app/__tests__/guards.test.ts`); cap `Heading` and `Display` text at `maxFontSizeMultiplier={1.3}` (`MAX_FONT_SIZE_MULTIPLIER` in `app/constants/theme.ts`).
- Every Bible verse rendered anywhere in Onboarding, Home peek, **ليا أنا** cards, History, and Favorites MUST use `<Scripture>` (`Amiri-Regular` / `Amiri-Bold`, user-selected `SCRIPTURE_SIZES` `[18, 20, 23, 27, 32]`, line-height `1.8`).
- Rich-text Markdown bodies for **أسماء الله** and **البركات** (`react-native-marked`) inherit `IBMPlexSansArabic-Regular` / `IBMPlexSansArabic-Bold`, `16px` body at `1.6` readable Arabic paragraph line-height (`26px`), and warm-paper foreground/border tokens; headings inside Markdown map to `20px` bold; blockquotes render with logical start border (`border-s-2 border-accent ps-4 bg-muted/40`).
- All numbers, counts, step indicators, and dates use `toArabicDigits()` and `formatArabicDate()` from `@roi/shared` (Arabic-Indic digits `٠١٢٣٤٥٦٧٨٩`).

## Screen & Interaction Contracts

### 1. Root Launch Routing (`app/app/index.tsx` + `ContentGate`)
- **Precondition:** `useMigrations` succeeds and `ContentGate` passes (`lastContentVersion > 0`).
- **Routing rule (`D-04`, `04-CONTEXT.md` Integration Points):**
  - If MMKV `onboarding_completed` is falsy: render Onboarding Screen 1 (`/onboarding` or state-gated onboarding stack with back disabled into `/` until completed).
  - If MMKV `onboarding_completed` is `true`: render **HomeScreen (`أدواتك`)** immediately offline.
  - Preserve `DEV_TOOLS_ENABLED` dev links (`شاشة اختبار النصوص`, `شاشة فحص التكاملات`) in a subtle dev footer on Home (never shown in release builds).

### 2. Onboarding Flow (`HOME-01`, `HOME-02`, `PERS-01`, `D-01`, `D-02`)
- **Shared Chrome:** Full-screen `bg-background` safe-area container (`px-6 py-8`), top 3-dot progress indicator (`١` / `٢` / `٣` with active dot `bg-accent` and inactive `bg-muted`), `KeyboardAvoidingView` / `ScrollView` for small screens.
- **Screen 1 — What Ro'i is (`عن روعي`):**
  - **Primary visual anchor:** Centered `Display` title `"روعي"` (`text-3xl font-bold text-foreground`) + tagline `"كلمتك، وهويتك، وصلاتك… في مكان واحد، وحد بيرعاك وإنت جواه."` (`text-base text-muted-foreground text-center`).
  - **Content:** 4 calm `bg-card rounded-2xl border border-border p-4` preview rows introducing the 4 tools (**ليا أنا**, **حفظ الآيات**, **تشفع**, **دفتر الشكر**) with `Icon` (`text-accent`), bold title (`text-base font-bold`), and 1-line Egyptian Arabic summary (`text-sm text-muted-foreground`).
  - **Primary CTA:** Full-width `Pressable` `"ابدأ الرحلة"` (`min-h-[44px] rounded-xl bg-primary px-6 py-4`, `text-sm font-bold text-primary-foreground`).
- **Screen 2 — Name & Gender (`عرفنا بنفسك`):**
  - **Primary visual anchor:** Heading `"نحب نناديك بإيه؟"` (`text-xl font-bold text-foreground`) + calm subtext `"عشان الآيات والكلام جوه روعي يكون مكتوب ليك بالاسم"`.
  - **Controls (both required per `D-01`):**
    1. Name `TextInput` (`min-h-[44px] rounded-xl border border-input bg-card p-4 text-base text-foreground text-start`, `placeholder="اكتب اسمك هنا"`, `autoCapitalize="words"`).
    2. Gender segmented selector (`accessibilityRole="radiogroup"`, 2 equal-width `Pressable` cards `min-h-[44px] rounded-xl border p-4`): **`ولد`** vs **`بنت`**. Selected chip uses `bg-primary border-primary text-primary-foreground font-bold`; unselected uses `bg-card border-border text-foreground`.
    3. Inline `text-destructive text-sm` validation message if user taps `"احفظ اسمي وكمّل"` with empty trimmed name or unselected gender.
  - **Persistence on submit:** Writes `profile.name` and `profile.gender` to syncable SQLite `settings` table (`D-04`) and advances to Screen 3.
- **Screen 3 — Starter Verses First Win + Optional Google Sign-In (`اختار أول آية`):**
  - **Primary visual anchor:** Personalized gender-aware heading `"اختار آية تبدأ بيها، يا {الاسم}"` (`"اختاري آية تبدأي بيها، يا {الاسم}"` for female) + helper `"دوس على النجمة ⭐ عشان تحفظها في مفضلتك، أو كمّل وتختار بعدين"`.
  - **Controls:**
    1. Search bar (`TextInput`, `min-h-[44px]`, `placeholder="ابحث في الآيات..."`, diacritic/variant-insensitive filtering via `matches()` from `@roi/shared`) + `"آيات تانية"` shuffle `Pressable` (`min-h-[44px] rounded-xl border border-border bg-card px-4 py-2`) picking 3–5 live verses from SQLite `verses`.
    2. 3–5 personalized verse cards (`bg-card rounded-2xl border border-border p-4 gap-2`), rendering `<Scripture>{personalize(v, profile)}</Scripture>`, `v.ref` (`text-sm text-muted-foreground`), and a `min-h-[44px] min-w-[44px]` ⭐ Favorite `Pressable` (`Star` icon: filled/tinted `text-accent` when starred with `accessibilityLabel="إزالة من المفضلة"`, `text-muted-foreground` when unstarred with `accessibilityLabel="أضف للمفضلة"`, `accessibilityState={{ selected: isFavorited }}`). Tapping ⭐ immediately inserts/toggles in SQLite `favorites` so the user achieves their **first win** (`HOME-02`) before leaving Screen 3.
    3. **Bottom Finish Actions (`D-01`, `D-02`, locked layout):**
       - Primary full-width `Pressable` `"استمر باستخدام جوجل"` (`min-h-[44px] rounded-xl bg-primary px-6 py-4`, `text-sm font-bold text-primary-foreground`). Tapping opens a calm `Dialog` explaining why Google Sign-In + `drive.appdata` is requested (*"حساب جوجل هيسمح لك تبعت اقتراحات لكل الناس دلوقتي، وهيجهّز نسخة احتياطية خاصة بيك في مجلد التطبيق المخفي على جوجل درايف في التحديث الجاي — من غير ما نشوف أي حاجة من بياناتك"*), with `"متابعة مع جوجل"` (`bg-primary`) and `"إغلاق النافذة"`. Requests `GoogleSignin` with `https://www.googleapis.com/auth/drive.appdata` (`D-02`). On success or cancellation/failure, shows calm notice if failed and never traps the user.
       - Directly centered beneath the primary button: small text-only `Pressable` `"استمر بدون تسجيل"` (`min-h-[44px] items-center justify-center px-4 py-2`, `text-sm text-muted-foreground underline`) allowing clean finish with or without starring a verse ("later").
    4. Completing via either action sets MMKV `onboarding_completed = true` and replaces route to Home (`أدواتك`).
