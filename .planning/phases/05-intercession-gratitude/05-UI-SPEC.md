## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (`IBMPlexSansArabic-Regular`) | 1.5 (24px) |
| Label | 14px (`text-sm`) | 700 (`IBMPlexSansArabic-Bold`) on buttons, active tabs, sort/filter chips, and person count badges; 400 (`IBMPlexSansArabic-Regular`) on timestamps, relative dates, and helper hints | 1.4 (20px) |
| Heading | 20px (`text-xl`) | 700 (`IBMPlexSansArabic-Bold`) | 1.3 (26px) |
| Display | 28px (`text-3xl`) | 700 (`IBMPlexSansArabic-Bold`) | 1.2 (34px) |

Typography rules:
- Strictly **4** UI sizes (`14px`, `16px`, `20px`, `28px`) and **2** UI weights (`400` `IBMPlexSansArabic-Regular`, `700` `IBMPlexSansArabic-Bold`).
- **Never** apply `tracking-*` utility classes (breaks Arabic ligature joining and fails `app/__tests__/guards.test.ts`).
- **Never** pass `allowFontScaling={false}` (fails `app/__tests__/guards.test.ts`); cap `Heading` and `Display` text at `maxFontSizeMultiplier={1.3}` (`MAX_FONT_SIZE_MULTIPLIER` in `app/constants/theme.ts`).
- Gratitude writing `TextInput` (both collapsed card and expanded full-screen canvas) uses `16px` (`text-base`) `IBMPlexSansArabic-Regular` at `1.5` line-height (`24px`), `textAlignVertical="top"`, and logical `text-start`.
- All numbers, prayer counts, progress counts (`فاضل {N} من {M}`), dates, and reminder times (`٩:٠٠ مساءً`) use `toArabicDigits()`, `formatArabicDate()`, and `EGYPTIAN_MONTHS` from `@roi/shared` (Arabic-Indic digits `٠١٢٣٤٥٦٧٨٩`).

### 6. Privacy, Telemetry, RTL & Static Guard Constraints
- **Telemetry (`app/constants/telemetry.ts`):** Only call `track('prayer_logged')` and `track('gratitude_saved')` with **zero parameters** — never log prayer body, person name, outcome, or gratitude text.
- **Notification privacy (`SET-04`):** Notification title/body are strictly static generic Arabic (`"روعي"` / `"لحظة هدوء قبل ما تنام — تحب تكتب سطر شكر النهاردة؟"`).
- **Soft deletes & append-only events (`FND-06`, `FND-07`):** Never call Drizzle `.delete()` in `app/{app,features,services,hooks}` (enforced by `schema.test.ts`); derive `prayedCount` and `lastPrayedAt` from live `prayer_events`.
- **RTL & A11y (`app/__tests__/guards.test.ts`, `eslint-plugin-react-native-a11y`):** Use logical Tailwind utilities (`start-*`, `end-*`, `ps-*`, `pe-*`, `ms-*`, `me-*`, `text-start`, `border-s-*`) only; include `accessibilityRole` + `accessibilityLabel` (+ `accessibilityState`) on every interactive element (`expo lint --max-warnings 0`).
